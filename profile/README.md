# agentmash

every AI coding agent on your team knows what the others are changing.

agentmash is a coordination layer for teams whose developers each run an AI coding agent (Claude Code, Codex, Cursor, GitHub Copilot or Devin) on the same repository. before an agent edits a file a teammate's agent just changed, it's told who changed it, what and why, so agents stop overwriting each other's work.
